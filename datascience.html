Data Science Course Syllabus

Course Duration: 50 Hours

Module 1: Introduction to Data Science (6 Hours)

  • What is Data Science?
  • Applications of Data Science
  • Data Science Life Cycle
  • Career Opportunities
  • Introduction to Python
  • Installing Python & Jupyter Notebook

Module 2: Python Programming Fundamentals (12 Hours)

  • Variables and Data Types
  • Operators
  • Conditional Statements
  • Loops (For, While)
  • Functions
  • Strings
  • Lists, Tuples
  • Dictionaries and Sets
  • File Handling
  • Exception Handling

Module 3: NumPy & Pandas (12 Hours)

  • Introduction to NumPy
  • Arrays and Operations
  • Indexing and Slicing
  • Statistical Functions
  • Introduction to Pandas
  • Series and DataFrames
  • Importing CSV Files
  • Data Cleaning
  • Handling Missing Values
  • Filtering and Sorting Data

Module 4: Data Visualization & EDA (10 Hours)

  • Introduction to Matplotlib
  • Line Charts
  • Bar Charts
  • Pie Charts
  • Introduction to Seaborn
  • Histograms
  • Box Plots
  • Heat Maps
  • Exploratory Data Analysis (EDA)
  • Data Interpretation

Module 5: Statistics & Probability (5 Hours)

  • Mean, Median, Mode
  • Standard Deviation
  • Variance
  • Probability Basics
  • Correlation and Covariance

Module 6: Machine Learning Basics (3 Hours)

  • Introduction to Machine Learning
  • Supervised Learning
  • Unsupervised Learning
  • Linear Regression
  • Classification Concepts

Module 7: Project & Assessment (2 Hours)

  • Mini Data Science Project
  • Dataset Analysis
  • Project Presentation
  • Interview Questions
  • Final Assessment
