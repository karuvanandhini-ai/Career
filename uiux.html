UI/UX Design Course Syllabus

Course Duration: 25 Days

Module 1: Introduction to UI/UX (Days 1–3)

  • What is UI and UX
  • Difference between UI and UX
  • Role of UI/UX Designer
  • Design Thinking Overview

Module 2: Design Fundamentals (Days 4–6)

  • Elements of Design
  • Principles of Design
  • Color Theory Basics
  • Typography Basics

Module 3: User Research (Days 7–9)

  • User Research Methods
  • User Personas
  • Empathy Mapping
  • User Journey Mapping

Module 4: Wireframing (Days 10–12)

  • Introduction to Wireframing
  • Low-Fidelity Wireframes
  • Sketching UI Ideas
  • Tools for Wireframing

Module 5: Figma Basics (Days 13–15)

  • Introduction to Figma
  • Figma Interface
  • Frames and Layouts
  • Basic Tools in Figma

Module 6: UI Design (Days 16–18)

  • Creating UI Components
  • Buttons, Cards, Forms
  • Icons and Images Usage
  • High-Fidelity UI Design

Module 7: Prototyping (Days 19–21)

  • What is Prototyping
  • Interactive Designs in Figma
  • Linking Screens
  • User Flow Design

Module 8: Responsive Design (Days 22–23)

  • Mobile First Design
  • Responsive Layouts
  • Breakpoints

Module 9: Portfolio & Project (Days 24–25)

  • UI/UX Portfolio Design
  • Case Study Preparation
  • Mini Project (App or Website UI)
  • Final Presentation
