Front-End Developer Syllabus

Course Duration: 120 Hours

Module 1: Introduction to Front-End Development

  • Overview of HTML, CSS, JavaScript, Bootstrap
  • Understanding how websites work
  • Setting up development environment
  • Exploring sample websites

Module 2: HTML Fundamentals

  • HTML Structure
  • Text formatting, links, images, lists
  • Tables and forms
  • Semantic tags
  • Mini Project: Personal Profile Page

Module 3: CSS Basics

  • CSS Types and selectors
  • Colors, fonts, text styling
  • Box model
  • Positioning

Module 4: Advanced CSS

  • Flexbox and Grid
  • Pseudo-classes
  • Animations and transitions
  • Responsive design
  • Project: Styled Landing Page

Module 5: Bootstrap Framework

  • Grid system
  • Components and utilities
  • Navigation, modals, carousel
  • Project: Responsive Website

Module 6: JavaScript Fundamentals

  • Variables and data types
  • Control structures
  • Functions
  • Arrays and objects

Module 7: JavaScript DOM & Events

  • DOM manipulation
  • Event handling
  • Form validation
  • Mini Project: Calculator / Form

Module 8: Advanced JavaScript

  • ES6 features
  • Array methods
  • Local storage
  • Timers and dynamic DOM

Module 9: UI Enhancement & Media

  • HTML5 APIs
  • Fonts and icons
  • CSS effects
  • Project: Gallery / To-Do List

Module 10: Integration & Optimization

  • Combining HTML, CSS, JavaScript
  • Performance optimization

Module 11: Version Control & Deployment

  • Git and GitHub
  • Deployment platforms

Module 12: Capstone Project

  • Project planning and development
  • Testing and deployment
