Python Course Syllabus

Course Duration: 60 Hours

Module 1: Introduction to Python (5 Hours)

  • What is Python and why it is used
  • Installing Python and IDE setup
  • Writing first Python program
  • Variables and data types
  • Input and output statements

Module 2: Control Structures (10 Hours)

  • If, elif, else statements
  • For loop and while loop
  • Nested loops
  • Break, continue, pass
  • Basic problem solving

Module 3: Functions & Modules (10 Hours)

  • Defining functions
  • Function arguments and return values
  • Lambda functions
  • Importing modules
  • Math and built-in modules

Module 4: Data Structures (10 Hours)

  • Lists and list operations
  • Tuples
  • Dictionaries
  • Sets
  • String handling methods

Module 5: File Handling & Exception Handling (10 Hours)

  • Reading files
  • Writing files
  • Appending data
  • Error handling (try, except)
  • Finally block

Module 6: OOP & Basics of Data Science (15 Hours)

  • Classes and objects
  • Constructors
  • Inheritance
  • Polymorphism
  • Introduction to NumPy & Pandas
