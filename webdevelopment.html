Web Development Course Syllabus

Course Duration: 45 Days

Module 1: Introduction to Web Development (Days 1–5)

  • What is Web Development
  • Frontend vs Backend
  • How Websites Work
  • Internet and Browsers
  • Introduction to HTML

Module 2: HTML Fundamentals (Days 6–10)

  • HTML Structure
  • Headings, Paragraphs
  • Lists (Ordered & Unordered)
  • Links and Images
  • Tables and Forms

Module 3: CSS Basics (Days 11–18)

  • Introduction to CSS
  • Inline, Internal, External CSS
  • Colors, Fonts, Backgrounds
  • Box Model
  • Margin and Padding
  • Positioning
  • Display Properties

Module 4: Advanced CSS (Days 19–25)

  • Flexbox Layout
  • CSS Grid
  • Animations
  • Transitions
  • Hover Effects
  • Responsive Design
  • Media Queries

Module 5: JavaScript Basics (Days 26–32)

  • Introduction to JavaScript
  • Variables and Data Types
  • Operators
  • Conditions (if/else)
  • Loops
  • Functions
  • Arrays

Module 6: DOM & Advanced JS (Days 33–38)

  • DOM Manipulation
  • Events
  • Forms Validation
  • Local Storage
  • Fetch API Basics

Module 7: Bootstrap & Responsive Design (Days 39–41)

  • Bootstrap Introduction
  • Grid System
  • Components
  • Navbar and Cards

Module 8: Final Project (Days 42–45)

  • Portfolio Website
  • Institute Website
  • Form Validation Project
  • Final Presentation
