Basic Computer Course Syllabus

Course Duration: 50 Hours

Module 1: Introduction to Computers (4 Hours)

  • What is a computer
  • Types of computers
  • Basic components (CPU, Monitor, Keyboard, Mouse)
  • Input and Output devices
  • Basics of operating systems (Windows overview)
  • File and folder management

Module 2: Microsoft Word (15 Hours)

  • Introduction to MS Word interface
  • Creating, opening, saving documents
  • Editing text (cut, copy, paste, undo/redo)
  • Formatting text (font, size, color, styles)
  • Paragraph formatting (alignment, spacing, bullets & numbering)
  • Page setup (margins, orientation, size)
  • Inserting elements:
    • Tables
    • Pictures
    • Shapes
    • Symbols
  • Headers and footers
  • Page numbers
  • Find and Replace
  • Spell check and grammar tools
  • Printing documents
  • Basic document design (letters, resumes)

Module 3: Microsoft PowerPoint (10 Hours)

  • Introduction to PowerPoint interface
  • Creating presentations
  • Slide layouts and themes
  • Adding text, images, and shapes
  • Slide transitions
  • Animations
  • Inserting audio/video
  • Slide show presentation
  • Printing slides and notes

Module 4: Microsoft Excel (21 Hours)

  • Introduction to Excel interface
  • Workbook and worksheet basics
  • Data entry and editing
  • Formatting cells (numbers, dates, text)
  • Rows, columns, and sheet management
  • Basic formulas:
    • Addition, subtraction, multiplication, division
  • Functions:
    • SUM, AVERAGE, MIN, MAX, COUNT
  • Sorting and filtering data
  • Creating charts (bar, pie, line)
  • Basic data analysis
  • Page setup and printing
  • Introduction to tables
  • Basic shortcuts and productivity tips
