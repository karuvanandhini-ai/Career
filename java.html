Core Java Course Syllabus

Course Duration: 60 Hours | Daily 2 Hours

Module 1: Basics of Programming and Java Introduction

  • Introduction to programming concepts
  • Java Installation
  • Writing first Java program
  • Data types, variables, and operators

Module 2: Control Structures and Arrays

  • Decision making / Conditional statements: if, if-else, else-if, switch
  • Loops: for, while, do-while
  • Arrays: single, two-dimensional, multi-dimensional
  • String handling

Module 3: OOPS Basics

  • Classes and Objects
  • Constructors: default, parameterized, copy
  • Inheritance: single, multilevel, hierarchical
  • Encapsulation and Polymorphism
  • Abstract classes and abstract methods
  • Reference data types

Module 4: Advanced OOPS and Exception Handling

  • Interfaces and multiple interface implementation
  • Java packages
  • Exception handling and try-catch mechanism
  • File handling: create, read, write, append files

Module 5: Revision and Practice

  • Recall all topics
  • Practice exercise programs
